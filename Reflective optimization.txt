reflective optimization in prompt space:
- the idea is, instead of updating weights, we can update the prompt. in case of a mistake, a single prompt can give a large behaviour change which is not possible with the updation of weights.
- GEPA (generic pareto): an algo which combines the above idea
- multi hop search: AI hops across different data sources to find an answer. in the first hop a query is run and generates a new query and in the subsequent hops, another search is conducted with the sub query. the information gathered from each hop is combined to form a comprehensive and accurate answer to the original query
